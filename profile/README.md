## Why PlayMAKER?

- **For every level:** Useful tools should be accessible to amateur and grassroots teams as well as larger organizations.
- **Made to fit:** Teams can customize their workflows and presentation.
- **Use what you need:** Each tool is designed to work independently, with interoperability across the ecosystem as it develops.
- **Open source:** Project code and progress are shared through public repositories as they become available.
- **Core features without mandatory AI:** Essential workflows are designed to work without requiring AI services.
